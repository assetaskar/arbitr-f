# Арбитраж-сканер — фронтенд

React 18 + Vite 5 + TypeScript. Интерфейс арбитраж-сканера: выбор бирж, режима пар
и порогов; таблицы межбиржевого спота, фьючерсов, базиса спот↔фьючерс и funding
обновляются в реальном времени по WebSocket.

Бэкенд живёт в отдельном репозитории:
**[arbitr-b](https://github.com/assetaskar/arbitr-b)** (FastAPI + ccxt).

Настройки принадлежат браузеру (`localStorage`) и уходят в свой WebSocket, поэтому
разные вкладки и устройства не влияют друг на друга.

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер поднимется на http://localhost:5173. Для живых данных нужен запущенный
бэкенд на порту 8000 — Vite проксирует на него `/api` и `/ws`
(см. `vite.config.ts`), поэтому CORS не требуется.

Сборка продакшена:

```bash
npm run build     # tsc --noEmit + vite build → dist/
npm run preview   # локальный предпросмотр сборки
```

## Docker

Многоступенчатая сборка: Vite собирает статику, nginx её раздаёт и проксирует
`/api` и `/ws` на бэкенд.

```bash
docker build -t arbitr-frontend .
docker run -p 5173:80 -e BACKEND_URL=http://backend:8000 arbitr-frontend
```

`BACKEND_URL` — адрес бэкенда, куда nginx проксирует запросы (подставляется в
`nginx.conf.template` при старте контейнера).

## Структура

```
src/
├── App.tsx             Корневой компонент, загрузка настроек, разводка данных
├── useLiveData.ts      WebSocket-сессия: шлёт настройки, принимает снимки
├── api.ts              REST-обёртки и хранение настроек в localStorage
├── types.ts            Типы, зеркалящие модели бэкенда
├── format.ts           Форматирование цен/процентов, подсветка спреда
├── index.css           Тёмная тема
└── components/
    ├── Header.tsx              Статус связи, возраст данных, «Обновить», ⚙
    ├── SettingsDrawer.tsx      Выезжающая панель настроек (Esc / клик мимо)
    ├── SettingsPanel.tsx       Биржи, режим пар, котировки, исключения, пороги
    ├── CrossExchangeTable.tsx  Межбиржевые расхождения (спот и фьючерсы)
    ├── BasisTable.tsx          Базис спот↔фьючерс внутри биржи
    └── FundingTable.tsx        Funding-спред между биржами
```

## Примечание

Приложение только отображает данные и не является инвестиционной рекомендацией.
